# MODE-1 台本・LP制作マニュアル

MODE-1 PARTNERS の実クライアント事例・添削記録から体系化された社内制作基準。
一般的なコピーライティング論ではなく、**このマニュアルの型に従って**制作物を作る。

## 使い方（必ずこの順で）

### STEP 0. 何を作るか確定させる

| 依頼内容 | 読むファイル |
|---|---|
| LP（種別が未確定） | `references/03_lp-types.md` の「はじめに」→ 種別を確定 → `references/02_lp-production-manual.md` |
| LP（種別が確定済み） | `references/02_lp-production-manual.md`（16セクション詳細・コピーサンプル）＋ `references/03_lp-types.md` の該当種別（設計パラメータ・FAQ・チェックリスト） |
| ローンチ動画（VSL）・YouTube長尺・リール | `references/04_launch-video-manual.md` |
| インスタ ストーリーローンチ | `references/01_script-manual.md` PART 1 |
| LINE配信シナリオ・失注ファネル | `references/01_script-manual.md` PART 4 |
| 添削・レビュー依頼 | 該当マニュアルの「NGパターン集」＋「完成チェックリスト」で1項目ずつ照合 |
| 全体像・他マニュアルの所在 | `references/00_package-index.md` |

**LP種別が不明なまま書き始めないこと。** 種別を誤ると全面やり直しになる。
不明なときは `03_lp-types.md` のQ&Aフロー（目的は販売か／セミナー集客か／個別相談か／記事か → 動画の有無）でユーザーに質問して確定させる。

### STEP 1. 制作前の必須確認

以下が揃っていなければ、**まずユーザーに確認する**（揃わないまま書くと必ずボツになる）。

- **ターゲット**：年代・職業・状況・「本人が普段使っている悩みの言葉」
- **ゴール**：LINE登録 / 個別相談申込 / セミナー申込 / 商品購入 の**どれか1つ**
- **独自ポジション・メソッド名**：競合と何が違うか（3C分析）
- **実績数字**：受講生の成果を Before → After 形式で3件以上
- **文体**：クライアント固有の口調（例：マーケ博士＝「〜じゃ」「わし」）
- **CTA先**：どこへ誘導するか／特典の中身

情報が足りない場合は、`references/04_launch-video-manual.md` の
「6-6. クライアント情報 収集チェックリスト」をそのまま質問リストとして使う。

### STEP 2. 該当マニュアルの型どおりに書く

構成・セクション数・各セクションの書き方・コピーサンプルはマニュアルに全部ある。
自分で構成を考えず、**マニュアルの構成をそのまま使う**。
穴埋めテンプレートは `references/04_launch-video-manual.md` PART 6 にある。

### STEP 3. 提出前にチェックリストで自己添削

該当マニュアル末尾の「完成チェックリスト」と「NGパターン集」で全項目を照合してから提出する。

## 全制作物に共通する5つの大原則

この5つに違反した制作物は、他がどれだけ良くても差し戻し。

| # | 原則 |
|---|---|
| ① | **What戦略**：何をするか（What）は伝える。どうやるか（How）は出さない。Howを全部出すと「自分でできそう」となり申込みが止まる |
| ② | **解決策には問題の種がある**：解決策を出した直後に新たな課題を提示し「だから専門家が必要」という流れを作る（PREP法サイクル） |
| ③ | **ビフォーアフター＋数字**：事例は「Before → After ＋ 数字 ＋ 属性」の3点セット必須。「良かったです」で終わらせない |
| ④ | **1コンテンツ1ゴール**：CTAの行き先は1つだけ。複数のゴールを入れると読者が迷い、どの行動も起こさない |
| ⑤ | **クライアント固有の文体を維持**：文体が変わると読者に違和感が生まれ、開封率・視聴率が下がる |

### 教育の8ステップ（全制作物の骨格）

信頼性の担保 → 欲求の自覚 → 理想の未来 → 問題点の指摘 → 解決策の提示（What）→ 再現性の担保 → 投資の重要性 → 行動の促進

## 絶対NGパターン（制作前に暗記すること）

| NG | 改善 |
|---|---|
| 「こんなお悩みありませんか？」でFVを始める | 数字インパクト・常識破壊・ベネフィット直球のいずれかで始める |
| 「まずやってみてください」と言う | 申込みが止まる最悪のワード。「詳細は個別相談で」に変える |
| Howを出しすぎる | Whatのみ提示。詳細はセミナー・個別相談の場に残す |
| 3つ以上の選択肢・コースを出す | 1〜2パターンに絞る（ジャムの法則） |
| 「〇期生募集」 | 遅れた感・損した感が出る。「先着〇名」「審査制」に変更 |
| 「多くの方が成果を出しています」 | 「3ヶ月で月商100万達成した〇〇さんの場合」と具体化 |
| 講師紹介が実績の羅列だけ | Before（共感）→ 転換点 → After（実績）＋使命感のストーリーに |
| 受講者の声が「良かったです」 | 数字＋ビフォーアフター＋属性（年代・職業・名前） |
| 価格を提示して終わり | 比較対象で「高い」を先に潰す → 分割 → ROI・1日換算 |
| CTAがFVと最後だけ | FV・中間・最後の3点に設置 |
| 冒頭を挨拶から始める（動画） | 冒頭3秒でフック。挨拶は不要 |
| 1通目を「特典プレゼント！」から始める（LINE） | 先にゴール（相談申込・LP）を訴求。特典は「さらに！」で後置 |
| LINEの配信間隔が5日以上空く | 最低3日に1回は配信する |
| マーケ用語で書く | 生活者言語で書く（「CVR」→「成約率」、「集客」→「予約が来ない」） |

### 個別相談LPだけの絶対ルール

**CTAボタンの直下に「高額商品の販売はありません」を必ず入れる。** これが個別相談申込みの最大の反論処理。

## ジャンル別の注意点

新しいクライアント・ジャンルへ転用するときは、構造・フック型・CTA設計はそのままで、
悩みの言葉と実績数字だけを差し替える。変換表は `references/04_launch-video-manual.md` PART 5 にある
（副業・インスタ集客／サロン・美容／子育て／英語・語学／ダイエット の5ジャンル）。

| ジャンル | 特記事項 |
|---|---|
| 子育て系 | 家族・一族を否定する表現はNG →「時代に合わない古い価値観」に。「まずやってみて」は特に厳禁 |
| サロン・美容系 | 緑系カラー（安心感）が有効。フォロワーの言葉遣いに合わせる |
| インスタ副業・在宅系 | 「これ一択」「どれも正解」はNG →「ライフスタイルによって正解が異なる」。顔出し不要の事例を必ず入れる |
| 英語・語学系 | 「正しいフォームなしに練習しても上達しない」の常識破壊から入る。年齢不安は「70代で成果」事例で先に潰す |
| BtoB向け | 感情より論理。ROI・投資対効果の数字を重視 |

## 品質の考え方

初稿が60点でも構わない。まず量を出して PDCA を高速で回すことが最短ルート（富樫流原則10）。
ただし提出前のチェックリスト照合だけは省略しない。

PDCA指標：LP＝CVR・滞在時間 ／ LINE＝開封率・クリック率・申込率 ／ ストーリー＝スタンプ反応・DM数 ／ 動画＝視聴完了率・申込率 ／ リール＝視聴完了率・コメント数・保存数
