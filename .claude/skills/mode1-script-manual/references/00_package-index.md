## このパッケージの使い方
| 新規クライアントに着手するとき | まず No.07（コンセプト設計）を読んで方針を固める → No.02/03（LP）→ No.01（台本）の順番で制作 |
|---|---|
| ローンチ動画を作るとき | No.04（ローンチ動画v2）→ PART5 ジャンル別転用ガイドで自分のジャンルの設計差異を確認 |
| セミナーを作るとき | No.07（コンセプト設計）で企画コンセプトを先に固める → No.08（セミナー台本）で台本を制作 |
| LINEシナリオを作るとき | No.05（LINE動線）のCh.2「オファータイプ」を最初に確認 → 対応するタイプのタイムラインを使う |
| インスタのストーリーを設計するとき | No.06（ストーリーローンチ）のCh.1でゴールを決める → Ch.7の全日程テンプレートを穴埋めする |
| 迷ったとき | 各マニュアル末尾の「完成チェックリスト」で抜け漏れを確認 → NGパターン集で自己添削 |

各マニュアルは独立して使えますが、コンセプト設計（No.07）が全施策の前工程です。どのマニュアルから始めても、コンセプトが固まっていない場合は必ずNo.07を先に確認してください。
本マニュアルパッケージは定期更新予定。最新バージョンはMODE-1 Google Driveで確認すること。
