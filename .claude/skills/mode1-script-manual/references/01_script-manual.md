# 01｜台本作成マニュアル【社内プロモーター研修版 v3】

> ストーリー台本 ／ LP台本 ／ ローンチ動画台本 ／ LINE台本
> MODE-1 PARTNERS / SATELLITE HOLDINGS　富樫惇史　2026年3月制定

# はじめに：このマニュアルの使い方
このマニュアルは、MODE-1 PARTNERSのプロモーターが担当クライアントの台本を制作する際の完全ガイドです。一般論ではなく「実際に手がけたクライアント事例・添削記録・LINEファネルの実データ」をもとに構築しています。
各台本は独立して機能するものではなく、ファネル全体の中でつながって機能します。まず全体像を把握した上で、各台本を制作してください。
## 5つの全体大原則
| 大原則① | What戦略を守る：何をするか(What)は伝える。どうやるか(How)は出さない。「まずやってみて」は申込みを止めるNG言葉 |
|---|---|
| 大原則② | 「解決策には問題の種がある」：解決策を出した後に新たな課題を提示し「だから専門家が必要」という流れを作る（PREP法サイクル） |
| 大原則③ | ビフォーアフター＋数字：事例は「Before→After＋数字」形式が必須。「良かったです」で終わらせない |
| 大原則④ | 1コンテンツ1ゴール：台本1本に入れるCTAは1つだけ。複数のゴールを入れると読者が迷い離脱する |
| 大原則⑤ | クライアント固有の文体を維持：マーケ博士なら「〜じゃ」。文体が変わると読者に違和感が生まれ開封・視聴率が下がる |

# STEP 0：制作前の必須確認事項
どの台本を制作するにしても、以下を必ず確認してから制作に入ること。
## 1. コンセプト確認
- [ ] ターゲット：誰の、どんな悩みに向けているか（年齢・状況・具体的な悩みの言葉）
- [ ] 独自ポジション：競合と比較してどこで戦うか（3C分析済みか）
- [ ] メソッド名・独自フレームワーク：クライアント固有の命名があるか（例：まりの式デザインメソッド・Yumiの法則）
- [ ] 訴求軸：恐怖・欲求・承認・安心のどれに刺すか
- [ ] 台本のゴール：読んだ相手に何をさせたいか（LINE登録・相談申込・セミナー視聴）

> **【NG】** コンセプトが決まる前に台本を書き始める → 後でボツになる。時間の無駄
## 2. Google Drive検索（既存クライアントは必須）
クライアント名＋「コンセプト」「台本」「ローンチ」などのキーワードで検索。既存資料の文体・温度感・訴求軸に合わせること。同じジャンルで資料がない場合は同ジャンルのクライアント資料を40%参考に。
## 3. プロデューサーへの事前確認
- [ ] ローンチ種別（セミナーローンチ / プロダクトローンチ / エバーグリーンファネル）
- [ ] コンセプト方向性の承認
- [ ] 台本構成（アウトライン）のレビュー
- [ ] 完成物の最終承認

# PART 1：ストーリー台本の作り方
## 1-1. ストーリーローンチとは
インスタのストーリーズを使って、商品発売前から発売後にかけて継続的に発信し、見込み客の「欲求」を育てながら自然にオファーへ誘導するローンチ手法。神田様ローンチ準備資料をベースに4フェーズで設計します。
| フェーズ1（14〜8日前） | 問題提起・期待感の醸成 → まだ何も売らない。アンケート・質問ボックスで関係構築 |
|---|---|
| フェーズ2（7〜4日前） | 教育・価値提供・ウォームアップ → What戦略で「続きが知りたい」状態を作る |
| フェーズ3（3日前〜前日） | オファー提示・緊急性の構築 → 日程・費用・特典を全公開。スタンプCTAで反応計測 |
| フェーズ4（募集3日間） | 限定性・緊急性訴求・申込み誘導 → 3日間の追い切り設計。最終日に申込みが集中する |

## 1-2. フェーズ別 制作テンプレート＋実例
フェーズ1：問題提起（14〜8日前）
- アンケート「集客は何を使っていますか？」→ 結果をシェアして共感を作る
- 受講生ビフォーアフターのチラ見せ（数字必須）
- 「セミナーやります」という予告チラ見せ（日程は出さない）
- 「どんな内容が見たいですか？」質問ボックス設置
- 質問ボックスの回答を1つずつ拾って返答 → 一体感を作る
📌 実例：マーケ博士リール台本集 No.6（ママ起業家事例）
**Before：** フォロワー30人のまま何ヶ月も投稿だけしていたが1件もDMが来なかった
**After：** 「フォロワー30人で月100万円達成」という逆説的なビフォーアフターをフェーズ1のチラ見せに使用。ストーリー閲覧数が3倍に。「数より熱量」というコンセプトが刺さり、フェーズ2への期待感が一気に高まった
> **【コツ】** 1枚のストーリーに伝えたいことは1つだけ。テキストは大きく・少なく・スマホで読みやすく
> **【NG】** フェーズ1で商品の詳細・価格・申込みURLを出す → 見込み客が離れる
フェーズ2：教育・価値提供（7〜4日前）
- 「〇月〇日に開催！」と日程を告知（ここで初めて日程を出す）
- 受講生の成功事例を数字付きで追加（「2ヶ月で新規32名」など）
- 「すでに〇〇名が参加表明」と社会的証明を作る
- 無料期間・有料化の期限を明示して緊急性を演出
- 特典サムネイルをチラ見せして価値を高める
📌 実例：マーケ博士リール台本集 No.15（フォロワー数より導線重要）
**Before：** 「フォロワーが増えてきたのに全然マネタイズできない」という状態
**After：** フェーズ2で「フォロワーが少なくても売上が出る理由」をWhat戦略で教育。「フォロワー85人で月216万円」「256人で月334万円」の実績を提示したことで、セミナー申込みが急増した
> **【What戦略】** 「コンセプト設計が必要です」「3つの要素を揃えてください」→ Howは出さない。「それは個別で教えています」で締める
フェーズ3：オファー提示（3日前〜前日）
- 日程・時間・参加費・特典・アーカイブなしを明記したストーリーを投稿
- 「絶対参加する人は🔥で教えて」スタンプCTAでエンゲージメントを取る
- 既存コンテンツ（ライブ・YouTube等）で価値提供し「続きはLINEで」誘導
- 前日は「ついに明日！」で期待感を最大化
> **【カラー指針】** 緑系（安心感）はサロン・子育て系、青紫系（プロ感）はビジネス系に有効（JV添削メモより）
フェーズ4：オープンカート（募集期間）
- 初日：募集開始アナウンス＋申込み方法をわかりやすく
- 2日目：追加の受講生の声（ビフォーアフター形式）
- 最終日：「本日23:59まで」の追い切り訴求
- 終了後：「〇名参加ありがとう」で次への期待感
📌 実例：えびな夫婦セミナー資料添削メモ
**Before：** 「参加してください」とただ告知していただけで、参加率・ショーアップ率が低い状態
**After：** 「先着〇名」「このセミナーを受けた数ヶ月後に必ず悩みが出てくる」という緊急性・必要性訴求を追加。オープンカート中も「受講生事例」を毎日1本投稿したことで最終日に申込みが集中した
## 1-3. ストーリー台本 完成チェックリスト
- [ ] 4フェーズが揃っているか
- [ ] フェーズ1にアンケート・問題提起が入っているか（まだ何も売っていないか）
- [ ] フェーズ2にWhat戦略での教育・社会的証明（数字付き事例）が入っているか
- [ ] フェーズ3にオファー詳細（日程・参加費・特典）が明記されているか
- [ ] フェーズ4に緊急性（期限・先着人数）が入っているか
- [ ] スタンプCTA・質問ボックスを適切な場所に配置しているか
- [ ] 1枚1メッセージの原則が守られているか
- [ ] Howを出しすぎていないか（What戦略）
- [ ] プロデューサーの確認を得ているか

# PART 2：LP台本の作り方
## 2-1. LPとは何か・目的の確認
LPの目的は1つ：「個別相談・セミナー申込み・LINE登録などの次のアクションを起こさせること」。マーケティング研修LP台本・まりのさんセミナー資料・明場さんセミナー資料をベースに16セクション構成を標準化しています。
## 2-2. LP台本 16セクション構成
| セクション1 | ファーストビュー（FV） → キャッチコピー（数字インパクト）＋サブコピー＋CTAボタン |
|---|---|
| セクション2 | 問題提起 → 5〜7個の悩みリスト（「自分のことだ」と思わせる具体性） |
| セクション3 | 追い打ち（根本原因の提示） →「なぜうまくいかないのか」の常識破壊・衝撃の事実 |
| セクション4 | 解決策の提示 → 商品・サービスの概要（Whatのみ、Howは出さない） |
| セクション5 | コース紹介 → ターゲット別コース比較・特徴（2パターンまで） |
| セクション6 | カリキュラム詳細 → ロードマップ・週次スケジュール（まりの式4STEPなど） |
| セクション7 | 提供物一覧 → 動画・テンプレート・サポート体制 |
| セクション8 | 講師紹介 → 経歴・実績・ビフォーアフターストーリー（月収8万円→5年連続1000万円など） |
| セクション9 | 受講者の声 → ビフォーアフター形式で3〜5事例（数字必須） |
| セクション10 | 修了後のキャリアパス → 受講後の理想の未来像 |
| セクション11 | 価格 → 通常価格→今回限定価格・分割払い・ROI計算 |
| セクション12 | 募集要項 → 先着人数・期間・参加条件（審査制にすると希少性UP） |
| セクション13 | 申込みの流れ → STEP1〜4で視覚化（申込フォーム→審査→結果→日程調整） |
| セクション14 | FAQ → 7〜10項目（想定される反論を全部潰す） |
| セクション15 | 最終CTA → 申込みフォーム誘導＋最後のメッセージ |
| セクション16 | 追伸（P.S.） → 緊急性・希少性の最後の一押し（3つ推奨） |

## 2-3. 各セクション詳細＋実例
セクション1：ファーストビュー（最重要）
LPの中で最も重要。3秒でスクロールをやめさせるフックが命。
✏️ まりのさんセミナー資料 FV構成の実例
メインキャッチ：「【2026年最新版】本物のデザイン力×案件獲得術 在宅で月30万円を叶える完全攻略プレミアム勉強会」
サブコピー：デザイナー歴17年・5年連続年商1000万円超え・Adobe公式案件受注の実績（数字の羅列でFVに権威性を持たせる）
CTA：「完全審査制 無料個別ロードマップ相談会に申し込む」（審査制＝希少性）
> **【NG】** 「こんなお悩みありませんか？」でLPを始める → テンプレ感が強く離脱率が上がる（品質基準より）
セクション2：問題提起
「自分のことだ」と感じる悩みを5〜7個並べる。具体性が命。
📌 実例：まりのさんセミナー資料 問題提起スライド（スライド31）
**Before：** 「デザインで悩んでいませんか？」という漠然とした問題提起
**After：** 「デザインスクールを卒業したのに実務レベルのスキルが身についていない」「クラウドソーシングに登録したが案件が取れない」「低単価案件ばかりで生活が安定しない」「前のスクールの支払いに追われている」など具体的な悩みに変更。参加者が「自分のことだ」と感じ、最後まで視聴してもらえるようになった
セクション3：根本原因の提示（常識破壊）
「衝撃の事実」を提示して、なぜうまくいかないのかの根本原因を明示する。
✏️ 明場さんセミナー資料 衝撃の事実（スライド22〜23）
「英検1級を持っている人でも映画を字幕なしで見られない」
「TOEICで900点を超えているのにネイティブの会話が聞き取れない」
→ 理由：日本の英語教育が音を教えていないから、という根本原因を提示
→ 読者が「じゃあどうすれば？」という状態を作ることに成功
セクション8：講師紹介（ビフォーアフター必須）
実績だけを羅列するのではなく、必ずビフォーアフターストーリーをセットで語る。
✏️ まりのさんセミナー資料 自己紹介構成（スライド10〜19）
Before：制作会社で月収8万円スタート。14時間労働で手取り19万円。FXで100万円を失い心療内科に通う
After：8年もがいた結果、5年連続年商1000万円超え・Adobe公式案件・大手企業のデザイン担当
→ 「でも元々は…」という謙遜フレーズから入ることで読者との共感を先に作る
→ 逆境ストーリー（失敗→苦悩→突破）が読者の感情を動かす
✏️ 明場さんセミナー資料 自己紹介構成（スライド15〜17）
Before：「大学4年時にLとRの発音が区別できていなかった。留学して初めて気づいた」
After：YouTube登録者21万人・著書Amazon発音部門1位・テレビ・ラジオ出演
→ 「私自身が日本人として一番苦しんだ経験者だから教えられる」という権威の作り方
セクション9：受講者の声（ビフォーアフター必須）
「良かったです」で終わらせない。必ずビフォーアフター＋数字形式で書く。
📌 実例：まりのさんセミナー資料 受講生の声（スライド190〜193）から抜粋
**Before：** 「受けてみてとても良かったです。先生も親切でした。」という漠然とした感想
**After：** 「これまで様々なスクール（合計5校）に通いましたが、どのスクールよりも有益なカリキュラムで親身に寄り添ってくれた。こんなにデザイナーの生活を変えたいと思う熱量のある方に出会ったのは初めてです」というスクール5校との比較＋具体性のある声に変更
📌 実例：明場さんセミナー資料 受講生の声（スライド90〜92）から抜粋
**Before：** 単に「リスニングが改善しました」という抽象的な声
**After：** 「仕事で英語を使う機会があるのにリスニングが苦手でコンプレックスでした。受講後は、なぜ英語が聞き取れないのかを納得感をもって理解できました。ネイティブとの会話への抵抗がなくなり映画の理解が劇的に改善しました。自信を持って英語に取り組めるようになりました（芝野さん 50代・建設業）」という職業・年代＋Before→Afterの具体的な変化を明記した形式に
セクション11：価格（投資対効果で語る）
- まず全体の価値を整理（提供物の市場価値合計）
- 「本来ならこれだけかかる」という比較対象を提示
- 今回の価格＋限定理由
- 分割払い対応で月々の負担を計算
- ROI計算（何ヶ月で回収できるか・1日換算何円か）
✏️ 明場さんセミナー資料 価格正当化フレーム（スライド115）
「英会話スクールに毎月2〜3万円を数年通い続けたコストは60〜100万円以上」
「間違った方法で費やした時間は絶対に返ってこない」
「正しい方法で最短で結果を出すことの価値を計算してほしい」
→ 高い値段を「損」ではなく「最短ルートへの投資」として正当化
セクション14：FAQ（反論処理）
申込みを迷う理由を全部潰す。まりのさん・明場さんのFAQ設計から抽出した鉄板項目。
| 「自分にできるか不安」 | →「ビジネス未経験の〇〇さんが2ヶ月で〇万円達成（事例）」。70代でも成果が出た事例を入れる（明場さん資料スライド119より） |
|---|---|
| 「時間がない」 | →「週1時間から始められます」「動画はいつでも視聴OK。毎日10分でも効果あり」 |
| 「高すぎる」 | →「1日換算〇円」「〇ヶ月で投資額を回収できるROI計算」を提示 |
| 「今すぐ必要ない」 | →「今の状況を続けると〇ヶ月後にはこうなります（危機感）」。締切を設ける |
| 「本当に自分のジャンルで成果が出るか」 | → 全90ジャンルの実績事例一覧。「担当者が個別に確認します」 |
| 「顔出しなしでもできるか」 | →「顔出しなしで成果を出した受講生の事例」を引用（公務員・副業NG会社員向け） |
| 「無料なのに怪しい」 | →「長期的に見て私自身が一番得をするから最大の価値提供を無料で行っている」と明記（まりのさんスライド226〜228より） |

## 2-4. LP台本 完成チェックリスト
- [ ] FVに数字インパクトのあるキャッチコピーがあるか
- [ ] 「こんなお悩みありませんか？」始まりになっていないか（NG）
- [ ] 講師紹介にビフォーアフターストーリーがあるか（実績だけの羅列になっていないか）
- [ ] 受講者の声はビフォーアフター形式＋数字＋職業・属性になっているか

- [ ] CTAは複数回（FV・中間・最後）設置されているか
- [ ] FAQに「顔出し不要か」「自分のジャンルで成果が出るか」の反論処理があるか
- [ ] 追伸（P.S.）が3つ入っているか
- [ ] 期生制度は使っていないか（遅れた感が出るためNG）
- [ ] プロデューサーの確認を得ているか

# PART 3：ローンチ動画台本の作り方
## 3-1. ローンチ動画とは
ローンチ動画（VSL）は、セミナー・個別相談へ誘導するための動画。LPと同じく「教育→信頼→オファー」の流れで設計するが、動画ならではの「話し方・熱量・間」が売上を左右する。セミナー資料作成マニュアル・JVセミナー添削メモ・まりのさん/明場さんセミナー資料をベースに構築。
## 3-2. ローンチ動画 6パート構成
| パート1（0〜2分） | 冒頭フック → 常識破壊・数字インパクト・問いかけの3択から選ぶ |
|---|---|
| パート2（2〜8分） | 問題提起＋共感 → 視聴者の現状・悩みの代弁（PREP法サイクル開始） |
| パート3（8〜20分） | 原因特定＋教育（What戦略） → なぜうまくいかないのかの根本原因＋解決策のWhat提示（Howは出さない） |
| パート4（20〜30分） | 解決策の提示＋実績証拠 → メソッド紹介・受講生事例（数字×ストーリー形式） |
| パート5（30〜40分） | オファー説明 → 商品内容・価格・特典（ROI計算含む） |
| パート6（40〜45分） | CTA＋反論処理 → FAQ・申込み方法・期限 |

## 3-3. 各パート詳細＋実例
パート1：冒頭フック（最重要 ＝ 最初の30秒）
| 常識破壊型 | 「〇〇を頑張っている人ほど失敗します」 例：「バズってる人を参考にしているのに全然伸びない人、パクり方が全部間違ってます（マーケ博士リール台本集より）」 |
|---|---|
| 数字インパクト型 | 「たった30日で売上2.5倍を達成した方法を公開します」 例：「フォロワー85人で月216万円達成の全手順」 |
| 問いかけ型（明場さん方式） | 「なぜ英語を一生懸命勉強しているのに、聞き取れないのか理由が自分でもわからない方はいますか？（リアクションボタン）」 → クイズ形式で視聴者を当事者として引き込む |

📌 実例：マーケ博士リール台本集 No.15（常識破壊型フックの実例）
**Before：** 「バズってる人を参考にしているのに全然伸びない」という状態の人向け動画で、普通に「伸ばし方を教えます」から始めていた
**After：** 「バズってる人を参考にしているのに全然伸びない人、パクり方が全部間違ってます。」という常識破壊型フックに変更。「自分もやってた！」という共感から離脱を防ぎ、視聴完了率が大幅向上した
パート3：What戦略の実践（最重要）
セミナー添削メモで最も繰り返し強調されているポイント。
- What（何をするか）は伝える → 「コンセプト設計が必要です」「3つの要素を揃えてください」
- How（どうやるか）は出さない → 「それは人によって違うので個別相談で」
- 「まずやってみて」はNG → 申込みが止まる（複数の添削メモで共通して指摘）
- 3つ以上のパターンを出すとNG → 「自分でできそう」となる
📌 実例：えびな夫婦セミナー資料添削メモ（What戦略の実例）
**Before：** ステップ1コンセプト設計について「若干話しすぎ？ノウハウが多い」という状態
**After：** 「whatでつなぎ、howは伝えない」という添削指示を受けて修正。「課題→問題→原因→解決（→手段）」の流れを徹底し、解決策の後に新たな問題の種を提示する形に変えたことで個別相談への誘導率が改善
✏️ 明場さんセミナー資料 What戦略の応用例（スライド27）
What：「英語のリスニングが伸びない原因は3つある：①プロソディー ②リエゾン ③リダクション」
How：「その3つをどう練習するかは10週間プログラムで個別指導します」
→ 何が問題かは教えるが、解決方法は申込んだ人だけに教えるという構造
パート4：実績証拠（数字×ストーリー形式）
📌 実例：マーケ博士リール台本集 No.5（テルさん事例）
**Before：** 実績として「月82万円達成」という数字だけを提示していた
**After：** 「1年半売上ゼロ→月82万円」というビフォーアフター＋「くすぶっていた自分が変われた等身大のストーリー」をセットで提示。「自分もできるかもしれない」という希望が申込み率改善につながった
📌 実例：明場さんセミナー資料 受講生の声（スライド92）
**Before：** 「リスニングが改善しました」という数字なしの感想
**After：** 「70歳・会社役員の榎本さんが『七十の手習い、リスニングが飛躍的に伸びた。年齢は関係ないと実感した』」という年齢・役職・具体的な感想をセットで提示。年代を超えた「自分にもできる」という普遍的な安心感を作った
パート6：反論処理
| 「時間がない」 | →「動画は永久視聴。週1時間から始められます。毎日10分でも筋肉は変わります（英語はスポーツ理論から）」 |

# PART 4：LINE台本の作り方
## 4-1. LINE配信の役割と全体設計
LINE配信は「集客→教育→申込み→リマインド」の全フェーズをカバーするCRM。ママスクLINE導線ライティング・失注ファネルLINE配信v2・LINE配信設計マニュアルブックをベースに設計する。
| ファネル1（メイン） | 流入→セミナー動画視聴→個別相談申込み誘導 （エバーグリーンファネル：一度構築すれば24時間365日自動で機能） |
|---|---|
| ファネル2（失注回収） | 面談後の失注タグ付与→特典配布→QMPSS SALON→OWオファー→個別再案内 |

> **【最重要原則】** 1シナリオ1ゴール。ゴールが複数あるとメッセージが散漫になり、読者がどこに向かえばいいか分からなくなる（LINE配信マニュアルブックより）
## 4-2. 登録経路（スタート）の把握
登録者がなぜLINEに登録したのかを明確にすることで、メッセージの温度感・前提知識・必要な教育量が決まる。
| インスタ経由 | ある程度の温度感がある。すでに発信者のコンテンツを見ている状態 |
|---|---|
| 広告経由 | コールドリード。信頼構築に時間が必要。教育量を多くとる |
| セミナー視聴後 | 最も温度が高い。個別相談への移行速度を上げる設計に |
| 紹介経由 | 第三者の信頼が転移している。紹介者への感謝を入れると効果的 |

## 4-3. 通数・タイミング設計
| 購買温度が高い場合 | 3日間8通シナリオ  Day0（流入直後・10分後・3時間後）→ Day1（朝・夜）→ Day2（昼・夜）→ Day3（昼） |
|---|---|
| 購買温度が低い場合 | 7〜14日間シナリオ  教育配信を多くとって信頼を積み上げてからオファーへ |
| 通数の鉄則 | Day0の3通（流入直後・10分後・3時間後）で信頼構築＋教育①が最も重要。登録直後が最も開封率が高い |

## 4-4. 各通の設計原則＋実例
配信1：登録直後（ウェルカムメッセージ）― 最重要
登録直後の配信は最も開封率が高い。以下を確実に含める。

📱 登録直後　マーケ博士ウェルカム配信の実例（失注ファネルv2より）
> **【本文構成】** ①「わしが直接話した縁を大切にしておる」という温かい書き出し ②「まず無料でQMPSSのメソッドを知ってほしい」という動画URLの提供 ③「今から見ると〇〇がわかる」という視聴メリットを3点 ④「さらに！特典もある」という特典は後から提示
> **【文体の特徴】** 「〜じゃ」「わしが」という固有の文体を完全維持。文体が変わると読者に違和感が生まれ開封率が下がる

| 1日後 21:30 | 夜のスキマ時間（子供が寝た後）→「この2時間で未来が変わる」訴求 |

📌 実例：ママスクLINE導線ライティング（時間帯設計の実例）

**After：** 子育て中のママの生活リズムに合わせて「21:30（子供が寝た後）」「12:30（昼休み）」という時間帯を設定。配信内容もその時間帯の心理状態に合わせて変更したことで開封率が改善
