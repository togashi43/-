# **STEP 2｜LP設計の3つの大前提**

LP制作に入る前に、以下3つの設計思想を必ず確認すること。コンセプトが定まっていない状態でライティングに入ると必ずやり直しになる。

| 大前提 | 内容 |
| :---- | :---- |
| ① What戦略 | LPで伝えるのは「何を解決できるか（What）」のみ。「どうやって解決するか（How）」はLP上で出しすぎない。Howを全部出すと「自分でできそう」となり申込みが来なくなる |
| ② 感情が先・理性が後 | 人は感情で購買を決め、理性で正当化する。まず感情を動かす（共感・恐怖・欲求）→ その後に理性的な理由（実績・価格・保証）を提供する |
| ③ コンセプトが9割 | LP制作に入る前にコンセプトを固めること。ターゲット・ポジション・独自性が決まっていないLPはどれだけ文章を磨いても成果が出ない |

## **教育の8ステップ（LP全体の流れ）**

LP全体の教育設計は以下の順番で設計する。

| 順番 | 内容 |
| :---- | :---- |
| ① | 信頼性の担保　— 「この人・この情報は信頼できる」と感じさせる |
| ② | 欲求の自覚　— 「自分はこれを本当に望んでいる」と気づかせる |
| ③ | 理想の未来　— 「こうなりたい」というビジョンを具体的に見せる |
| ④ | 問題点の指摘　— 「今のままではそこに辿り着けない」と気づかせる |
| ⑤ | 解決策の提示　— 「この方法なら解決できる（What）」を提示する |
| ⑥ | 再現性の担保　— 「自分でもできそう」という確信を受講生の声で示す |
| ⑦ | 投資の重要性　— 「ここに投資することが合理的」と理性に訴える |
| ⑧ | 行動の促進　— 「今すぐ申し込む」という感情的な背中の一押し |

# **STEP 3｜コンセプト設計を固める（3C分析）**

LPの文章は「コンセプトの見える化」。以下を確認してからライティングに入ること。

## **3C分析チェックリスト**

* 【自社】クライアントの実績・強み・独自のメソッドが明確か

* 【競合】同ジャンルで戦っている人のLP・セミナー内容・訴求軸を把握しているか

* 【顧客】ターゲットの悩みの言葉・検索ワード・SNSのコメントを集めているか

* 【差別化】「なぜこの人からこの商品を買うのか」という理由が1行で言えるか

## **訴求候補の洗い出し（使う訴求軸は2〜3個まで）**

| 訴求軸 | コピー例 |
| :---- | :---- |
| 特別感・希少性 | 「先着10名限定」「審査制」「あなただけに」 |
| 再現性・簡易性 | 「〇〇するだけで」「初心者でも3ヶ月で」「ゼロから」 |
| ストーリー・共感 | 「私も同じ悩みを抱えていた」「元〇〇の私が」 |
| 権威性・実績 | 「受講生〇名突破」「Amazon〇部門1位」「TV出演歴」 |
| 最悪の未来・恐怖 | 「このままだと〇年後にはこうなる」「知らずにいると損をする」 |
| 理想の未来・欲求 | 「〇ヶ月後にはこんな生活ができる」「毎朝が楽しくなる」 |
| 共通の敵 | 「古いやり方は通用しない」「〇〇業界の常識は嘘だった」 |
| 社会的証明 | 「〇〇人が受講」「受講生の声〇件以上」「9割が継続」 |

# **STEP 4｜LP種別別 全セクション構成と書き方**

## **💎 バックエンド販売LP**

| 目的：有料商品・講座を直接販売する |
| :---- |
| **文字量：**5,000〜15,000文字が標準。金額が高いほど長くなる |
| **位置づけ：**ファネルの最下層。セミナー・個別相談を経た後のクロージングページ |

| Sec 1 | FV：数字インパクト型キャッチコピー＋CTAボタン　— 3秒で離脱を止める最重要セクション |
| :---: | :---- |

**キャッチコピーの3パターン**

| パターン | コピー例 |
| :---- | :---- |
| 数字インパクト型 | 「フォロワー85人で月216万円達成の全手順を公開」「30日で、売れる仕組みを自分の手で作る」 |
| 常識破壊型 | 「英語を毎日勉強しているのにリスニングが伸びない人へ」「インスタのフォロワーを増やしても稼げない理由」 |
| ベネフィット直球型 | 「デザイン歴17年・5年連続年商1000万円超えの現役デザイナーが30日だけ教える」 |

| ✗ NG：「こんなお悩みありませんか？」でFVを始める → テンプレ感で3秒離脱 |
| :---- |
| **✗ NG：**「〇〇の方法を教えます」という曖昧な表現 → 数字とベネフィットを入れる |
| **✓ CTAボタンの型：**「【審査制・先着10名限定】今すぐ無料キャリア相談会に申し込む」※「申し込む」より「相談する」「受け取る」の方がCVRが高い傾向あり |

| Sec 2 | 問題提起：ターゲットが抱える具体的な悩み 5〜7個　— 「自分のことだ」と思わせる |
| :---: | :---- |

* 悩みは「状況描写」＋「感情」の2層で書く（状況だけでは刺さらない）

* 「〇〇しているのに〇〇できない」という逆説形が共感を生む

* 5〜7個のうち1〜2個は「ターゲットが言語化できていなかった悩み」を入れると信頼度が上がる

| コピーサンプル（サロン集客版） |
| :---- |
| ・毎日インスタを投稿しているのに、新規のお客様が全然来ない |
| ・ホットペッパーに月5万円払っているのに、費用対効果が出ていない |
| ・フォロワーは増えてきたのに、なぜか予約につながらない（言語化できていなかった悩み） |

| Sec 3 | 根本原因：なぜ自力では解決できないのかの常識破壊　— 「だから自分でやっても無理だ」と気づかせる |
| :---: | :---- |

| パターン | 内容 |
| :---- | :---- |
| 常識破壊型 | 「99%の〇〇が勘違いしていること」例：「英語のリスニングが伸びない人の95%が聞く量が足りないと思っているが、本当の原因は音のルールを知らないから」 |
| 衝撃の事実型 | 統計・データ・実績で現状の厳しさを提示 |
| 自分でやっても無理型 | 「正しいフォームなしに練習しても上達しない」→ 自己解決の限界提示から専門家の必要性へ |

| Sec 4 | 解決策の提示（What）　— Howは絶対に出さない |
| :---: | :---- |

| ✗ NG：解決策のHowをLP上で全部説明する → 「自分でできそう」となり申込みが来なくなる |
| :---- |
| **✗ NG：**「まずやってみてください」という表現 → 申込みが止まる |
| **✓ OK：**「〇〇の3つの要素を揃えることで解決します（What）。それぞれの詳細はキャリア相談会でお伝えします（How保留）」 |

| コピーサンプル（穴埋め） |
| :---- |
| 「この問題を解決するには、たった〇つのことを変えるだけです。」 |
| 「具体的には、①〇〇　②〇〇　③〇〇 の3ステップです。」 |
| 「それぞれをどう実践するかは、あなたの状況によって異なります。」 |
| 「だからこそ、まずは無料の個別相談会でご確認ください。」 |

| Sec 5 | コース・プログラム紹介　— 2パターンまで。選択肢を増やさない |
| :---: | :---- |

* コースは最大2パターンまで。3パターン以上にすると読者が迷い、どれも選ばなくなる

* 「対象者の違い」を明確にする。価格差がある場合は「なぜ違うか」の理由も明記する

| ✗ NG：スタンダード・プレミアム・エンタープライズという3パターン以上 → 迷いを生む |
| :---- |
| **✓ OK：**「クライアントワークで稼ぎたい人向け」vs「自分の商品を売りたい人向け」という明確な分け方 |

| Sec 6 | カリキュラム詳細　— ロードマップで「どんな自分になれるか」を見せる |
| :---: | :---- |

* 週次・月次のロードマップ形式で表示する

* 「受講後にどんな状態になっているか」を具体的にイメージさせることがゴール

* 「添削チェックポイント」を明示するとサポート体制の手厚さが伝わり安心感が生まれる

| Sec 7 | 提供物一覧　— 受け取れるものの「総価値」を見せる |
| :---: | :---- |

| カテゴリ | 記載内容 |
| :---- | :---- |
| 講義動画（見放題） | コンセプト設計・商品設計・LPライティング・LINE導線設計など各講義タイトルを列挙 |
| テンプレート | Canvaテンプレート〇種類・各テンプレートの用途を明記 |
| サポート体制 | 専用Slackチャンネル・グループコンサル・添削回数・サポート期間を明記 |
| 特典・その他 | 数値管理シート・AIツール紹介・外注先リスト・素材一式など |

| Sec 8 | 講師紹介　— 実績の羅列ではなくビフォーアフターストーリーで信頼を作る |
| :---: | :---- |

| ブロック | 内容 |
| :---- | :---- |
| Block 1：共感（Before） | 「でも元々は…」という謙遜フレーズから入る。過去の失敗・苦悩を隠さず語り読者との共通点を作る |
| Block 2：転換点 | 「そんなとき〇〇に出会い…」「〇〇をやってみたら…」という転換点のストーリー |
| Block 3：実績（After）＋使命 | 「現在は〇〇を達成した」という結果＋「だからこそ同じ悩みを持つ人を助けたい」という使命感で締める |

| 📌 実例：まりのさんセミナー資料 |
| :---- |
| **Before：**「デザイン歴17年・Adobe公認」という実績の羅列だけ |
| **After：**「月収8万円・14時間労働・FXで100万円を失い心療内科通い（Before）」→「8年もがいた末に行き着いたメソッド（転換点）」→「5年連続年商1000万円超え（After）＋使命感」というストーリー構成に変更。「この人から買いたい」という信頼が生まれた |

| Sec 9 | 受講者の声　— 「良かったです」厳禁。数字＋ビフォーアフター形式が必須 |
| :---: | :---- |

| 必須要素 | 内容 |
| :---- | :---- |
| 数字 | 「2ヶ月で月間新規32名」「売上3倍」「50万円達成」など。数字がないと証明にならない |
| ビフォーアフター | 「受講前は〇〇でした → 受講後は〇〇になりました」の明確な対比 |
| 属性 | 「30代・会社員（副業）」「50代・建設業・芝野さん」など職業・年代・名前。誰が言っているかで信頼度が変わる |

| ✗ NG：「受けてみてとても良かったです。先生も親切でした。」（どう変わったか不明） |
| :---- |
| **✗ NG：**「売上が上がりました」（数字がない） |
| **✓ OK：**「集客未経験でインスタが何もわからない状態（Before）→ 運用2ヶ月で月間新規32名達成・現在は40名以上で安定（After）（30代・サロン経営）」 |
| **📌 最強の声：**「以前は〇〇スクール/方法を試していたが成果が出なかった→こちらで改善した」という比較型 |

| コピーサンプル（穴埋め） |
| :---- |
| 「受講前は（Before：具体的な悩みの状況）という状態でした。」 |
| 「受講後は（After：具体的な数字・変化）を達成しました。」 |
| 「今では（After継続）しています。（〇〇・〇代・〇〇さん）」 |

| Sec 10 | 修了後のキャリアパス　— 受講後の理想の未来を具体的にイメージさせる |
| :---: | :---- |

* 受講後にどうなるかを具体的に見せる。複数の進路オプションがある場合は分岐図で視覚化

* 「採用を保証するものではありません」という免責も必ず明記する

| Sec 11 | 価格　— 「高い」という感情を先に潰す。投資対効果で正当化する |
| :---: | :---- |

| 手順 | 内容 |
| :---- | :---- |
| ① 価値整理 | 提供物の市場価値を合計して見せる |
| ② 比較対象の提示 | 「本来ならこれだけかかる」という比較対象を先に提示して「高い」感情を先に潰す |
| ③ 今回の価格＋限定理由 | なぜ今回だけこの価格なのかの理由を明記する |
| ④ 分割払い対応 | 「月々〇円から」と月額換算・日割り換算で負担感を下げる |
| ⑤ ROI計算 | 「何ヶ月で回収できるか・1日換算何円か」を計算して提示する |

| 📌 実例：明場さんセミナー資料 |

# **STEP 5｜全LP共通の設計ルール**

セクション制作時に必ず守ること。LP種別にかかわらず全ての制作物に適用する。

## **FV・キャッチコピー**

* ✅ 数字インパクトで始める

* ✅ 権威・ベネフィット・数字の組み合わせ

* ❌ 「こんなお悩みありませんか？」でFVを始めない（テンプレ感で即離脱）

## **CTA設計**

* ✅ 動画直下・中間・最終の3点に設置する（読者が決意するタイミングは一人ひとり違う）

* ✅ 「申し込む」より「相談する」「受け取る」

* ✅ CTAボタンの上下に緊急性の文言を挟む

* ✅ 個別相談LPは「高額商品の販売はありません」をCTAボタン下に必ず入れる

## **What戦略（情報量の制御）**

* ✅ 「何を知れるか（What）」だけを提示する

* ❌ Howを出しすぎない（「セミナーに行かなくていいか」となる）

* ✅ 詳細はセミナー・個別相談の場で伝える設計にする

## **講師紹介の型**

* ✅ Before（共感） → 転換点 → After（実績）の順番で書く

* ✅ 「だから同じ悩みの方を助けたい」という使命感で締める

* ❌ 実績の羅列だけで終わらせない

## **受講者の声・事例**

* ✅ 数字＋ビフォーアフター＋属性の3点セット

* ✅ スクリーンショット形式が最も信頼性が高い

* ❌ 「良かったです」だけでは証拠にならない

## **緊急性・希少性の演出**

* ✅ 削除告知バーを最上部に設置する

* ✅ 先着制・期間限定・審査制を明示する

* ✅ 「無料の理由」を3つ正直に開示する

* ✅ 「対象外の方」を先に書いて逆説を活用する

## **価格の正当化（バックエンドLPのみ）**

* ✅ 比較対象を先に提示して「高い」という感情を先に潰す

* ✅ 分割払いで月々の負担まで計算して見せる

* ✅ ROI（何ヶ月で回収か）を計算して提示する

# **STEP 7｜完成チェックリスト**

## **制作前の確認**

* LP種別が正しく選定されているか（STEP 1のQ\&Aフローで確認）

* ターゲットの3C分析が完了しているか（STEP 3を参照）

* LPのゴール（次のアクション）が1つに絞られているか

* コンセプトを作る手順を参照して訴求候補を洗い出しているか

* セクション構成がこのマニュアルと合致しているか

## **各セクション チェック（バックエンドLP）**

* Sec 1（FV）：「こんなお悩みありませんか？」始まりになっていないか

* Sec 1（FV）：数字インパクト・常識破壊・ベネフィット直球のいずれかになっているか

* Sec 2（問題提起）：「自分のことだ」と思わせる具体的な悩みが5〜7個あるか

* Sec 3（根本原因）：「だから自分一人では解決できない」という文脈になっているか

* Sec 4（解決策）：HowではなくWhatのみを提示しているか。「まずやってみて」と言っていないか

* Sec 5（コース）：2パターンまでに絞られているか。期生制度を使っていないか

* Sec 8（講師紹介）：ビフォーアフターストーリーが入っているか（実績の羅列だけになっていないか）

* Sec 9（受講者の声）：数字＋ビフォーアフター＋属性（職業・年代）の3点セットになっているか

* Sec 11（価格）：投資対効果（ROI計算・1日換算・比較対象）が入っているか

* Sec 12（募集要項）：先着人数・審査制など希少性・緊急性が演出されているか

* Sec 14（FAQ）：7〜10項目あるか

* Sec 15（最終CTA）：感情的な背中の一押しがあるか

* Sec 16（P.S.）：緊急性・実績・背中の一押しの3点が入っているか

## **ライティング全般チェック（全LP共通）**

* CTAが複数回（FV・中間・最後）設置されているか

* What戦略が守られているか（Howを出しすぎていないか）

* ターゲットが普段使う言葉で書かれているか（業界用語・マーケ用語を使っていないか）

* スマホで読みやすい改行・文字数になっているか

* 全体の教育の流れが「信頼→欲求→理想→問題→解決→再現性→投資→行動」になっているか

## **最終確認**

* プロデューサーへのアウトライン共有が完了しているか

* プロデューサーの最終承認を得ているか
