## はじめに：5種類のLPを使い分ける

LPは目的によって構成・文体・CTA設計が大きく異なる。**どのLPを作るかを最初に決めてから制作に入ること。誤った種別で制作すると全面やり直しになる。**
制作依頼を受けたら、まず下記のどれを作るのかをユーザーに質問して確定させること。

| 種別 | 概要 |
|---|---|
| ① バックエンド販売LP | 有料商品・講座・プログラムを直接販売する。最も長文。価格・カリキュラム・受講生の声を詳細に掲載。CVRより1申込の単価が重要 |
| ② セミナー集客LP（動画あり） | オンラインセミナー・ウェビナーへの参加予約を促す。LP冒頭に説明動画を設置し、動画後の温まった状態でCTAに誘導。テキストは補足として短め |
| ③ セミナー集客LP（動画なし） | 動画なしでテキストのみで訴求。コネクトLP（えびな夫婦）参照。長めの構成。問題提起→セミナー内容紹介→特典→CTA→FAQ の順 |
| ④ 個別相談LP（動画あり） | 個別相談・個別面談・ロードマップ作成会への申込みを促す。神田さんエバーグリーンLP参照。動画でWhatを教育しきり、その後テキストでCTA |
| ⑤ 個別相談LP（動画なし） | ちばデートLP参照。動画なしでテキストのみ。より短く・シンプルに構成。72時間限定・先着制の緊急性訴求が核心 |
| ⑥ 記事LP（3パターン） | ブログ記事のような形式で読者を誘導。A：ストーリー型 / B：問題解決型 / C：比較・暴露型。読者が自発的にスクロールして読む設計 |

各種別の**16セクション詳細・コピーサンプル・穴埋めテンプレート**は
`02_lp-production-manual.md` の「STEP 4｜LP種別別 全セクション構成と書き方」を参照すること。
本ファイルは種別ごとの**設計パラメータ・FAQ・チェックリスト**を扱う。

## ① バックエンド販売LP

| 項目 | 内容 |
|---|---|
| 位置づけ | ファネルの最下層。セミナー・個別相談を経た後に誘導するか、広告から直接誘導するか両方あり |
| 文字量 | 最長。5,000〜15,000文字が標準。スクロールが長くても離脱させない構成設計が重要 |
| 価格帯 | 5万円〜100万円以上。価格が高いほど証拠（事例・実績）の量と質が重要 |
| CTA文言 | 「申し込む」ではなく「まず相談する」「審査に申し込む」の方がCVRが高い場合が多い |

### チェックリスト
- [ ] FVに数字インパクト・権威・ベネフィット直球のいずれかのキャッチコピーがあるか
- [ ] 解決策はWhatのみを提示しているか（Howを出しすぎていないか）
- [ ] 講師紹介にビフォーアフターストーリーがあるか（実績の羅列だけになっていないか）
- [ ] 受講者の声は数字＋ビフォーアフター＋属性の3点セットになっているか
- [ ] 価格に投資対効果（ROI・1日換算・比較対象）が入っているか
- [ ] CTAが複数回（FV・中間・最後）設置されているか
- [ ] FAQが7〜10項目あるか（顔出し不要・ジャンル対応・時間・価格の反論処理があるか）
- [ ] P.S.が3点入っているか（緊急性・実績・背中の一押し）
- [ ] 期生制度は使っていないか（先着制・審査制に変更）

## ② セミナー集客LP（動画あり）

| 項目 | 内容 |
|---|---|
| 動画の長さ | 3〜8分が最適。長すぎると離脱。セミナーで話す内容をチラ見せして「続きはセミナーで」の構造 |
| テキストの役割 | 動画の補足・FAQの先取り・CTA誘導が主な役割。動画があるのでテキストは短くてよい |
| CTAの位置 | 動画直下に最初のCTAを設置（動画を見た直後が最も申込み意欲が高い） |
| 緊急性の出し方 | 「このページは〇日〇時に削除されます」という期限告知がページ最上部に来る（めぐみさん・ちばデートLP実例） |

### FAQ 鉄板項目
| 質問 | 回答の方向性 |
|---|---|
| Q. 参加方法は？ | → オンライン開催。通信環境と集中できる環境のみ必要。スマホ可 |
| Q. アーカイブはある？ | → リアルタイム参加のみ。アーカイブ・録画の配布はない（緊急性を維持するため） |
| Q. 初心者でも大丈夫？ | → 大丈夫。初心者こそ参加してほしい（「むしろ」という強調が効果的） |
| Q. 無料なのに怪しい？ | → 無料の理由を明記（ZONE 7参照） |
| Q. 質問はできる？ | → セミナー参加者はどんな質問もOK（参加特典として提示） |

### チェックリスト
- [ ] ページ最上部に削除告知バー（期限・緊急性）が入っているか
- [ ] 動画の前に「⇩まずはこちらをご視聴ください⇩」の誘導テキストがあるか
- [ ] 動画直下にCTAボタンが設置されているか（ここが最も重要な位置）
- [ ] CTAボタン後に「期間終了後は有料に切り替わる」の注意書きがあるか
- [ ] セミナー内容は❶〜❻で箇条書きになっているか（Whatのみ・Howは出していないか）
- [ ] 特典は7〜8個・タイトル＋1行説明＋サムネ形式になっているか
- [ ] 参加対象外→おすすめの方の順で記載されているか
- [ ] 無料の理由が明記されているか（怪しさを先に潰しているか）
- [ ] FAQが5項目以上あるか

## ③ セミナー集客LP（動画なし）

| 項目 | 内容 |
|---|---|
| 構成の違い | 動画なし → テキスト量が増える。共感パート・セミナー内容・ベネフィットの説明が詳細になる |
| 文字数 | 動画ありより長め。ただし冗長にならないよう箇条書きを多用 |
| FVの工夫 | 動画がない分、FVキャッチコピーのインパクトが特に重要。画像・ビジュアルで補う |
| CTAの数 | 動画なしは中間CTA（3〜4箇所）を多く設置する。読み疲れる前に申込みを促す |

### チェックリスト
- [ ] FVキャッチコピーに数字と限定性が入っているか
- [ ] 共感パートの悩みリストに具体的な数字・時間・状況が入っているか
- [ ] 実績提示に「ビフォーアフター数字」が使われているか
- [ ] セミナー内容はWhatのみでHowを出しすぎていないか
- [ ] CTAが3〜4箇所に設置されているか（FV・中間・最後）
- [ ] 特典は5〜7個・タイトル＋1行説明になっているか
- [ ] FAQにアーカイブなし・無料の理由・録画不可の旨が書かれているか
- [ ] 最後に「追伸：本気で変えたい方へ」の感情的な締めがあるか

## ④ 個別相談LP（動画あり）

| 項目 | 内容 |
|---|---|
| 心理的ハードル | 「個別で話すのが怖い・押し売りされそう」という不安が最大の障壁。LP全体でこの反論を先に潰す |
| 動画の役割 | 「問題提起→根本原因→解決策（What）→事例→個別相談の必要性」を30〜45分で教育する |
| テキストの役割 | 動画の補足・社会的証明・FAQ・CTA。**「高額商品の販売はありません」の明記が重要** |
| CTA設計 | 「ヒアリングフォーム→日程調整→個別相談」の2段階設計。一段階ではなく事前フォームを経由させる |

### FAQ 鉄板項目
| 質問 | 回答の方向性 |
|---|---|
| Q. 参加費はかかる？ | → 完全無料。費用は一切かからない（無料を2回強調する） |
| Q. 難しい知識が必要？ | → 不要。今の状況を教えていただければ十分 |
| Q. 相談したら何か買わないといけない？ | → 購入を強制することは一切ない（**最重要反論処理**） |
| Q. インスタ・Googleを始めていなくてもOK？ | → むしろそこからスタートの方が最短で成果が出る |
| Q. 自分のレベルで相談していいか不安 | → むしろ今まさに悩んでいる方に来てほしい |

### チェックリスト
- [ ] FVキャッチコピーが問いかけ型（なぜ〇〇なのか？）または数字インパクト型になっているか
- [ ] 動画直下に共感ゾーン（悩みリスト）が設置されているか
- [ ] 事例はBefore＋After＋数字の3点セットになっているか（3件以上）
- [ ] 個別相談の誘導に「全体の30%しかお伝えできていない」という文脈があるか
- [ ] CTAボタンの下に「高額商品の販売はありません」の反論処理テキストがあるか
- [ ] FAQに「購入強制なし」「費用無料」「難しい知識不要」が含まれているか
- [ ] 最終CTAに先延ばし防止の緊急性訴求（複利・今動くか）があるか

## ⑤ 個別相談LP（動画なし）

| 項目 | 内容 |
|---|---|
| 構成の短さ | 動画ありより短め。ファーストビューで緊急性を全面に出し、スピード感ある構成 |
| 緊急性の出し方 | 「72時間限定」「先着20名」「年に一度開催するかどうか」という3つの希少性を繰り返す |
| 申込み方法 | 「LINEカレンダーで日程選択」という簡単3ステップが効果的（フォームより心理的ハードルが低い） |
| 無料の正当化 | 「自分の可能性を諦めてほしくない」「長期的に私が得をするから無料にできる」の2軸で説明 |

### チェックリスト
- [ ] ページ最上部に72時間限定・先着制の緊急性告知が入っているか
- [ ] FVに「完全無料・先着〇名」の希少性が入っているか
- [ ] 自己紹介がビフォーアフターストーリー形式になっているか（実績の羅列NG）
- [ ] 「漠然とした悩みでもOK」「むしろそういった方に来てほしい」の文章があるか
- [ ] 特典は7〜8個・タイトル形式で入っているか
- [ ] CTAの上下に緊急性・希少性の文言が挟まれているか
- [ ] 無料の理由が正直に2〜3つ書かれているか
- [ ] 申込み方法が簡単3ステップ（クリック→日程選択→確定）になっているか

## ⑥ 記事LP（3パターン）

| 項目 | 内容 |
|---|---|
| 通常LPとの違い | FV・価格・特典などのLP臭が薄い。ブログ記事のような見た目で始まる。読了率・滞在時間が高い |
| 向いている場面 | SNS広告・SEO記事からの誘導・インフルエンサーのブログリンク・LINEの教育配信からの誘導 |
| CTA設計 | 記事中に自然に埋め込む（「詳しくは→ここ」という形式）。1〜3箇所が上限。多いと記事感が薄れる |
| 文体 | 「です・ます」調ではなく「〜だ・〜である」の断定調 or 体験談の「〜でした」調が多い |

### パターンA：ストーリー型
| 項目 | 内容 |
|---|---|
| 構成 | ①タイトル（読みたくなるもの）→ ②問題提起（主人公の悩み）→ ③挫折・転換点 → ④解決策（What）→ ⑤結果 → ⑥「あなたも同じことができる」→ ⑦CTA |
| タイトルの型 | 「〇〇だった私が〇ヶ月で〇〇を達成した話」「〇〇で悩んでいた私が変われた理由」 |
| 実例 | 「フォロワー30人・売上ゼロだった私が3ヶ月で月100万円を達成した話」（マーケ博士リール台本集 No.6参照） |
| CTA位置 | 記事の中盤（転換点の後）と記事末尾の2箇所 |

### パターンB：問題解決型
| 項目 | 内容 |
|---|---|
| 構成 | ①タイトル（悩み解決系）→ ②問題の定義 → ③原因の分析（3〜5点）→ ④各原因の解説（What）→ ⑤「でも自力では難しい理由」→ ⑥CTA |
| タイトルの型 | 「〇〇がうまくいかない人の共通点3つ」「〇〇で失敗する人がやっている5つのこと」 |
| 実例 | 「インスタで集客できていない人の共通点3つ（コンセプトなし・Howだけ投稿・フォロワー数優先）」 |
| What戦略 | 各原因の説明はWhat（何が問題か）のみ。Howを出しすぎると「自分でできそう」となる |
| CTAへのつなぎ | 「これらを自分のケースに当てはめるには、状況によって正解が異なります→だから個別相談で」 |

### パターンC：比較・暴露型
| 項目 | 内容 |
|---|---|
| 構成 | ①タイトル（常識破壊系）→ ②「多くの人が信じている常識」の提示 → ③常識の否定（衝撃の事実）→ ④「では何が正しいか？」→ ⑤事例で証明 → ⑥CTA |
| タイトルの型 | 「〇〇をやっている人ほど失敗する理由」「〇〇が正解だと思っている人がほぼ全員間違っている件」 |
| 実例 | 「インスタのフォロワーを増やすほど稼げなくなる理由」（マーケ博士リール台本集・常識破壊型フック参照） |
| 注意点 | 暴露・常識破壊は読者の感情を動かすが、ネガティブすぎる表現はNG。「業界を叩く」のではなく「正しい方法を知れば変わる」という希望で締める |

### 記事LP チェックリスト
- [ ] タイトルに「誰の・何の悩みを・どう解決するか」が凝縮されているか
- [ ] 冒頭の書き出しで「自分のことだ」という共感が生まれるか
- [ ] Whatのみで教育しHowを出しすぎていないか（自力解決を促していないか）
- [ ] CTAが記事内に自然に埋め込まれているか（多すぎず1〜3箇所）
- [ ] 文体が一貫しているか（です・ます or だ・である の統一）
- [ ] 記事末尾に「まとめ→CTAへの自然な誘導」があるか
- [ ] 事例（数字＋ビフォーアフター）が1件以上入っているか

## 全LP種別 共通 最終確認チェックリスト

### 制作前の確認
- [ ] LP種別（バックエンド／セミナー集客動画あり・なし／個別相談動画あり・なし／記事LP）を最初に確定させているか
- [ ] コンセプト設計（ターゲット・ポジション・独自性・訴求軸）が完了しているか
- [ ] LPのゴール（次のアクション）が1つに絞られているか
- [ ] Google Driveで既存クライアントの参照資料を確認しているか
- [ ] プロデューサーへのアウトライン共有が完了しているか

### 制作後の確認
- [ ] コンセプト、企画の期日、限定性に不備はないか確認する
- [ ] ボタンのワードが最適か確認する
- [ ] FVに数字・緊急性・権威のいずれかのインパクトがあるか
- [ ] CTAが適切な回数・位置に設置されているか（FV・中間・最後）
- [ ] What戦略が守られているか（Howを出しすぎていないか）
- [ ] 受講者・参加者の声に数字＋ビフォーアフター＋属性が入っているか
- [ ] 反論処理（FAQ・無料の理由・押し売りなし）が適切に配置されているか
- [ ] 期生制度は使っていないか（先着制・審査制に変更）
- [ ] スマホで読みやすい文字サイズ・改行・文字数になっているか
- [ ] プロデューサーの最終承認を得ているか
