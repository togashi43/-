# はじめに：ローンチ動画台本の全体設計
ローンチ動画は「教育 → 信頼 → オファー」の3ステップで設計します。単純に商品を紹介するのではなく、視聴者が「自分の問題に気づき → この人なら解決できると信頼し → 申し込みたくなる」という心理の流れを作ることがゴールです。
| 動画の種別 | ①YouTube長尺（15〜60分）②ローンチ動画VSL（30〜45分）③リール台本（15秒〜3分） |
|---|---|
| 共通する原則 | What戦略を守る（Howを出しすぎない）・冒頭3秒でフック・数字×ストーリーで実績証明 |
| 最重要指標 | 視聴完了率（滞在時間）＞コメント＞保存＞いいね の順番で重要度が高い |
| 制作前の確認 | コンセプト設計・ターゲット設定・プロデューサーへのアウトライン共有を先に完了させる |

> **【最重要ルール】** 「まずやってみて」はNG。申込みが止まる。Whatは伝えるがHowは個別相談・セミナーで、という流れを必ず作ること
# PART 1：YouTube長尺台本の作り方
## 1-1. YouTube長尺台本とは
15〜60分の動画で教育コンテンツを届けながら、最後にLINE登録・個別相談・セミナーへ誘導する台本。マーケ博士YouTube台本（商品設計5ステップ・心理学20選）が最も詳細な実例です。
| 目的 | 見込み客の教育（What戦略）→ 信頼構築 → LINE登録 or セミナー申込みへの誘導 |
|---|---|
| 構成 | OP（オープニング）→ 本編（コンテンツ）→ ED（エンディング・特典誘導） |
| 文体 | クライアント固有の文体を維持（マーケ博士：「〜じゃ」「わしが」） |
| 特典誘導 | 動画の最後に「特典はLINEから」という形で毎回必ず設計する |

## 1-2. OP（オープニング）の設計
OP-1  フック：視聴者の共感を引き出す常識破壊  — 最初の30秒で離脱を止める
OPは「この動画を最後まで見るべき理由」を伝える場所。以下の3ステップで設計する。
- 問いかけ or 衝撃の冒頭（「〇〇している人ほど失敗します」「フォロワー○人で月〇万円達成した方法」）
- ターゲットの悩みの言語化（「インスタを頑張っているのに売れない方へ」等、視聴者の状況を代弁）
- この動画で得られるベネフィットの提示（具体的な数字を入れる）
✏️ 台本サンプル：マーケ博士YouTube台本（商品設計5ステップ）OPより抜粋
マーケ博士：「多くの人が商品設計を難しく考えすぎておる。」
→「1万人フォロワーがいないと収益化できない」「専門知識や資格が必須」「会社員の給料を超えるなんて無理」
→ こんな風に思っていないかのぉ？
さえない君：「う、うん。確かに僕には無理そうだなって...」
マーケ博士：「じゃが、それは大きな勘違いなんじゃ！」
→「フォロワー320人で月54万円・680人で月72万円」の実績を提示
→「今日は小フォロワーでも月50万円を達成できる商品設計の5ステップを解説する」
> **【ポイント】** 常識破壊（1万人必要という思い込みを否定）→ 実績数字 → この動画で得られる価値の提示
📌 実例：マーケ博士 NG10選 OP
Before：「今から動画を始めます！よろしくお願いします！」という挨拶から始めていた
After：「今から300万円の話をする。いいか、ワシはこれまで5年間、500人以上のコンテンツ販売者を見てきた。その中で、半年で300万円をドブに捨てた人間を何人も見た——」という衝撃的な数字から始める形式に変更。視聴者が「え、何?」と思い、離脱率が大幅に改善
> **【コツ】** 「この動画は絶対に飛ばさず一気通貫で見てほしい（倍速はOK）」という一文を入れると視聴完了率が上がる（マーケ博士リール極意より）
OP-2  みるべき理由の提示  — フォロワーを最後まで引きつける「参加費」を払わせる
なぜこの動画を見るべきか・なぜこの人物が教えられるのかを、数字と実績で提示する。
✏️ 台本サンプル：みるべき理由の型
> **【実績の提示】** 「わしが起業3年で年商1.5億を達成した方法をフル活用した内容じゃ」
> **【受講生の実績】** 「受講生の総売上は50億円を突破しており、全90ジャンルで収益化を達成しておる」
> **【希少性の提示】** 「書籍の内容をインスタバージョンに再度活用した内容も含む」
> **【特典誘導の予告】** 「動画の最後に超有料級特典の受け取り方も紹介するので最後まで見るんじゃ！」
> **【ポイント】** みるべき理由を3〜4点に絞る。多すぎると読まれない
## 1-3. 本編（コンテンツ）の設計
本編  PREP法 × What戦略 × CRETA法の組み合わせ  — コンテンツを構造化して教育する
本編は「課題 → 問題 → 原因 → 解決策（What）→ 新たな問題の種 → CTA」のPREP法サイクルを繰り返す。
| PREP法 | Point（結論）→ Reason（理由）→ Example（具体例・実績）→ Point（再結論）の順番で各ノウハウを解説 |
|---|---|
| CRETA法（本編の大構成） | Conclusion（結論）→ Reason（理由）→ Evidence（証拠・実例）→ Technique（方法）→ Action（行動） |
| What戦略 | What（何をすべきか）は伝える。How（どうやるか）は「個別相談・セミナーで」と保留する |
| 解決策の後の問題の種 | 「解決策を伝えた直後に新たな課題を提示」→「だから専門家が必要」という流れを必ず作る |

✏️ 台本サンプル：マーケ博士台本「商品設計ステップ3」より構成抽出
> **【P：結論】** 「超シンプルな商品コンセプトの作り方は、穴埋め式で作れるんじゃ」
> **【R：理由】** 「なぜなら誰でも簡単に商品コンセプトが作れるからじゃ」
> **【E：具体例】** 「テンプレ：【誰に】が抱える【悩み】を【強み】を使って【期間】で【理想の未来】を実現させる【商品形式】」
→「このテンプレートを使ったGさんはフォロワー290人で月42万円達成（数字×ストーリー）」
> **【P：再結論】** 「つまり、たったこのフレームを埋めるだけで商品コンセプトができる」
> **【問題の種】** 「ただし、コンセプトを作ったとしても、それを誰に・どうやって届けるかが次の壁になる」
→「それをどう解決するかは個別相談でお伝えしています」（Howを保留してCTAへ）
> **【NG】** 「まずやってみてください」「自分で試してみてね」→ 申込みが止まる絶対NGワード
> **【重要】** コンテンツが多いと「自分でできそう」となり申込みが来なくなる。3〜5ステップに絞り、各ステップにWhatだけを提示する
> **【数字の使い方】** 「少なく見積もってそれぞれ1.3倍になるだけでも売上が2倍になる」など、数字を使って視聴者に変化をイメージさせる
## 1-4. 受講生事例の語り方（数字×ストーリー）
事例は「数字だけ」では伝わらず、「ストーリーだけ」では証明にならない。必ず「数字×ビフォーアフターストーリー×属性」の3点セットで語る。
| NGパターン | 「フォロワー320人で月54万円達成しました」という数字だけの提示 |
|---|---|
| OKパターン | 「30代主婦のAさんは、インスタ運用開始から4ヶ月目。専業主婦で特別なスキルも実績もゼロの状態から、5ステップを忠実に実践しただけで旦那さんの給料を超える月54万円を達成しました」という属性・状況・数字・ストーリーのセット |

📌 実例：マーケ博士YouTube台本（商品設計）受講生事例の書き方
Before：「フォロワー320人で月54万円達成」という数字のみの提示
After：「Aさんは子育ての合間に少しでも稼げたらと思って始めた専業主婦（Before：属性・状況）。わしが今日教える5ステップを忠実に実践しただけで、旦那さんの給料を超える月54万円を達成（After：数字）。しかもインスタ運用開始からたった4ヶ月目（期間）」という形式に。「自分もできるかも」という希望が生まれ、申込み率が改善
> **【事例の数】** 一本の動画に3〜6件の事例を散りばめる。多すぎると単調になるので、ステップごとに1件ずつ紐づけるのが最も効果的
## 1-5. ED（エンディング）の設計
ED  特典誘導 + LINE登録CTA + チャンネル登録依頼  — 視聴者の次のアクションを設計する
EDは「今日学んだことの復習 → 特典の価値提示 → 緊急性 → LINE登録CTA → チャンネル登録依頼」の順番で設計する。
✏️ 台本サンプル：マーケ博士YouTube台本 ED構成（実例）
> **【復習】** 「今回解説した商品設計の5ステップは...」（ステップを箇条書きで復習）
> **【実績再提示】** 「このステップを踏んだ方たちが実際に成果を出しています」
→ フォロワー320人で月54万、680人で月72万、890人で月63万（数字で締める）
【特典の価値提示（緊急性）】
「現在こちらの公式LINEでは——」
「総テキスト量93031文字・総スライド枚数1135枚・総動画再生時間580分・マンガ講義動画10本」
「という超特大ボリュームの有料級教材25個を期間限定で無料配布中じゃ」
> **【緊急性】** 「この特典はいつ受け取れなくなるかわからないので今のうちに下の概要欄から登録しておくのじゃ」
> **【特典受け取り方法】** 「合言葉『商品設計』を送るのじゃ」
> **【チャンネル登録依頼】** 「こういった動画を見逃したくない人はチャンネル登録とベルマークのクリックもお願いします」
> **【いいね・コメント依頼】** 「この動画が少しでもためになったという方はコメント欄に感想やいいねもお待ちしております」
> **【EDの長さ】** EDは1〜2分以内に収める。長すぎると離脱する。特典の価値と緊急性を簡潔に伝えることが重要
> **【合言葉設計】** 「合言葉を送る」という仕組みを使うことで、視聴者の行動を具体的に設計できる。合言葉は動画テーマに関連したワードを選ぶ
## 1-6. YouTube長尺台本 完成チェックリスト
- [ ] OPにフック（常識破壊・数字インパクト・問いかけ）があるか
- [ ] 「この動画を最後まで見るべき理由」を3〜4点提示しているか
- [ ] 本編はPREP法（結論→理由→具体例→再結論）で構成されているか
- [ ] What戦略が守られているか（Howを出しすぎていないか）
- [ ] 「まずやってみて」と言っていないか
- [ ] 受講生事例は「数字×ビフォーアフター×属性」の3点セットになっているか
- [ ] 各ステップの後に「問題の種（新たな課題）」を提示して次の教育につなげているか
- [ ] EDに特典の価値提示・緊急性・LINE登録CTAが入っているか
- [ ] クライアント固有の文体が維持されているか
- [ ] プロデューサーへのアウトライン共有が完了しているか

# PART 2：ローンチ動画（VSL）台本の作り方
## 2-1. ローンチ動画（VSL）とは
VSL（Video Sales Letter）は、セミナー・個別相談への申込みを促すための30〜45分の販売動画。YouTube長尺と構成は似ているが、「申込みを促すクロージング」に特化した設計になっている。
| YouTube長尺との違い | YouTube長尺は「教育が主目的・チャンネル登録が最終CTA」。VSLは「教育しながら申込みを促すことが主目的」 |
|---|---|
| LP内での位置づけ | 個別相談LP・セミナー集客LPのファーストビュー直下に設置。動画を見た直後が最も申込み意欲が高い |
| 動画の長さ | 30〜45分。長めでもOK（内容が濃ければ見る）。3〜8分の短い動画はセミナーLPに使う |
| クロージング構造 | What戦略で教育しきり → 反論処理 → CTA（申込みボタン）の流れ |

## 2-2. VSL 6パート構成
| パート1（0〜3分） | 冒頭フック（常識破壊・数字インパクト・問いかけの3択） |
|---|---|
| パート2（3〜10分） | 問題提起＋共感（視聴者の現状・悩みの代弁） |
| パート3（10〜25分） | 根本原因＋What戦略（なぜうまくいかないのかの根本原因 + 解決策のWhat提示） |
| パート4（25〜35分） | 実績証明（受講生の数字×ストーリー形式で3〜5件） |
| パート5（35〜40分） | オファー説明（セミナー・個別相談の内容・価格・特典） |
| パート6（40〜45分） | 反論処理＋CTA（FAQ + 押し売りなしの明記 + 申込みボタン） |

## 2-3. 各パート詳細＋実例
パート1  冒頭フック（最重要）  — 最初の30秒で離脱を止める
| 常識破壊型 | 「〇〇を頑張っている人ほど失敗します」 例：「バズってる人を参考にしているのに全然伸びない人、パクり方が全部間違ってます」（マーケ博士リール極意より） |
|---|---|
| 数字インパクト型 | 「たった30日で売上2.5倍を達成した方法を公開します」 例：「フォロワー85人で月216万円達成の全手順を公開します」 |
| 問いかけ型 | 「なぜ〇〇しているのに〇〇できないのか？」 例：「なぜ頑張っているのに新規が来ないのか？（神田さんLP台本より）」 → リアクションボタンやアンケートを使って視聴者を当事者として引き込む |

📌 実例：マーケ博士リール極意 常識破壊フックの実例
Before：「バズってる人を参考にしているのに全然伸びない動画」で、普通に「伸ばし方を教えます」から始めていた
After：「バズってる人を参考にしているのに全然伸びない人、パクり方が全部間違ってます。」という常識破壊型フックに変更。再生数が1万再生と10万再生で10倍の差になった（インサイトで確認済みの実例）
パート2  問題提起＋共感  — 視聴者の悩みを代弁して「これは自分のことだ」と思わせる
✏️ 台本サンプル：神田さん個別相談LP 共感ゾーン（実例）
「あなたは今、こんな悩みを抱えていませんか？」
☑ インスタに毎日投稿しているのに、新規予約につながらない
☑ Googleには登録しているけど、そこから予約が来た実感がない
☑ ホットペッパーに掲載しているのに、新規がジリジリ減っている
☑ リールを投稿しているのに再生数も伸びないし反応がない
☑ 何が正しくて、何から始めればいいのかが全く分からない
「一つでも当てはまるなら、この動画はあなたのために作られています。」
> **【ポイント】** 悩みの言語化は☑形式で5〜6個が最適。具体的な状況（時間・費用・行動）を入れると共感度が上がる
パート3  根本原因＋What戦略  — 最重要パート。なぜうまくいかないかを教育する
このパートが最も申込み率に影響する。What戦略を徹底し、Howを出しすぎないことが鉄則。
- What（何をするか・何が問題か）は伝える → 「コンセプト設計が必要です」「3つの要素を揃えてください」
- How（どうやるか）は保留する → 「それは人によって違うので個別相談・セミナーでお伝えします」
- 解決策の後に問題の種を提示する → 「〇〇が解決できても、次に〇〇という問題が出てきます」
📌 実例：えびな夫婦セミナー資料 What戦略の添削実例
Before：コンセプト設計について「若干話しすぎ？ノウハウが多い」という状態
After：「whatでつなぎ、howは伝えない」という添削指示を受けて修正。「課題→問題→原因→解決（→手段）」の流れに変更し、各解決策の後に新たな問題の種を提示。「自分でやってみよう」から「個別相談に行かないと」という心理に変化し、申込み率が改善
✏️ 台本サンプル：What戦略の応用（明場さんセミナー資料スライド27より）
What：「英語のリスニングが伸びない原因は3つある：①プロソディー ②リエゾン ③リダクション」
→ 何が問題かは教える（What）
How（保留）：「その3つをどう練習するかは10週間プログラムで個別指導します」
→ 解決方法は申込んだ人だけに教える（Howを保留）
問題の種：「この3つを知っても、実際に矯正するには正しいフィードバックが必要です」
→ 新たな課題を提示して「だから専門家が必要」という流れを作る
> **【NG】** 3つ以上のパターン・選択肢を出す → 「自分でできそう」となり申込みが来なくなる。2パターンまでに絞る
パート4  実績証明  — 数字×ストーリーで再現性を見せる
実績は「数字だけ」では証明にならず、「ストーリーだけ」では数字がなく信頼されない。両方をセットで使う。
📌 実例：マーケ博士YouTube台本 受講生事例の進化
Before：「月82万円達成」という数字だけを提示していた
After：「1年半売上ゼロ → 月82万円」というビフォーアフター＋「くすぶっていた自分が変われた等身大のストーリー（元ブランク企業サラリーマン）」をセットで提示。「自分もできるかもしれない」という希望が申込み率改善につながった
✏️ 台本サンプル：理想的な事例の語り方（型）
「〇〇さん（属性：30代主婦・副業NG会社員など）は——」
「Before：（状況・悩みを具体的に）〇〇という状態でした」
「（転換点）そんな中、〇〇に気づいたんです」
「After：（数字）〇ヶ月で〇万円を達成しました」
「今では（継続）〇〇という状態で安定しています」
> **【重要】** 事例は3〜5件。パート3で学んだ解決策を「この方はこう実践した」と紐づけて語ると説得力が増す
パート5  オファー説明  — セミナー・個別相談の価値を伝える
オファーは「売り込み」ではなく「あなたの悩みを解決できる場を案内する」というスタンスで語る。
- 「今日の動画でお伝えできたのは全体の30%です」という文脈でオファーへつなぐ
- セミナー・個別相談で何ができるか（Whatのみ）を箇条書きで提示
- 参加費（無料 or 有料）・所要時間・開催方法（Zoom等）を明記
- 「高額商品の販売はありません」「押し売りはしません」の明記（反論処理を先に行う）
✏️ 台本サンプル：神田さんLPオファー誘導コピー（実例）
「今日の動画でお伝えできたのは、全体の30%です。」
「残りの70%は『あなたのサロンに合わせた個別設計』の部分です。」
個別相談でできること：
・あなたのサロンの現状をヒアリング
・どの媒体から優先すべきかを明確に
・最短で結果を出すためのアクションプランをお渡し
参加費：無料 / 所要時間：約60分
「※高額商品の販売はありません。安心してご参加ください。」（← 最重要反論処理）
パート6  反論処理＋最終CTA  — 申込みを阻む反論を全部潰してから最後のボタンを押させる

✏️ 台本サンプル：最終CTA 緊急性訴求の型（神田さんLP実例）
「今動くか」「また先延ばしにするか」その選択が、半年後を決めます。

# PART 3：リール台本の作り方
## 3-1. リールの役割とアルゴリズム
リールはYouTubeやLPと同様に重要な教育ツール。ただし短尺（15秒〜3分）のため、「1本1メッセージ」の原則が特に重要。フォロワー数に関係なく拡散するため、新規集客の主力ツールでもある。
| 重要指標の順番 | 視聴完了率（滞在時間）＞コメント＞保存＞いいね（マーケ博士リール極意より） |
|---|---|
| 拡散の仕組み | フィード投稿はフォロワーの20〜30%にリーチ。リールはフォロワーの150〜300%にリーチし、その60〜80%はフォロワー外 |
| バズる条件 | 冒頭1〜3秒でフック → 滞在時間を伸ばす仕掛け → コメントを誘発するツッコミどころ → トレンド音源 |
| What戦略 | リールでもWhatのみ提示。Howは「詳しくはプロフのリンクから（LINE登録）」と保留 |

## 3-2. リール台本の6ゾーン構成
| Zone 1（0〜3秒） | フック：冒頭3秒で「続きを見たい」と思わせる。スクロールを止める一言 |
|---|---|
| Zone 2（3〜10秒） | 問題提起：ターゲットの悩みを代弁。「あるある」で共感を生む |
| Zone 3（10〜40秒） | コンテンツ本体：ノウハウ・実績・事例をWhat戦略で提示（3〜5点） |
| Zone 4（40〜50秒） | ツッコミどころ・コメント誘発：「〇〇派？〇〇派？」「これ知ってた？」 |
| Zone 5（50〜60秒） | CTA：「詳しくはプロフのリンクから」「LINEで〇〇を無料配布中」 |
| Zone 6（最後1〜2秒） | 余韻・引き：「次回は〇〇を解説する」「答えはコメント欄で」 |

## 3-3. フックパターン（3種類）＋実例
▶ フックパターン1：常識破壊型
視聴者が信じている常識を否定することで「え？」という状態を作り出す。
✏️ 台本サンプル：実例（マーケ博士リール台本より）
「バズってる人を参考にしているのに全然伸びない人、パクり方が全部間違ってます」
「毎日投稿するほど、実は伸びにくくなります」
「ChatGPTには隠れた弱点があるって知ってた？」（1000コメント・3000いいね獲得）
「インスタで稼ぐのに、フォロワー数は関係ありません」
> **【型】** 「〇〇（ターゲットがやっていること）をやっている人ほど〇〇（失敗・損）します」
▶ フックパターン2：数字インパクト型
具体的な数字で「え、本当に？」という驚きを作り出す。
✏️ 台本サンプル：実例
「フォロワー85人で月216万円達成した方法」
「1年半売上ゼロ→月82万円。その差を生んだ1つのこと」
「1500万円失いました...（マーケ博士リール・1000コメント以上獲得）」
「3ヶ月でマイナス10kg達成。やったことは〇〇だけ」
> **【型】** 「数字（Before）→ 数字（After）。その差を生んだのは〇〇だった」
▶ フックパターン3：問いかけ・クイズ型
視聴者に答えさせることで当事者として引き込む。コメントも誘発しやすい。
✏️ 台本サンプル：実例（明場さんセミナー資料・ダイアログ式より）
「なぜ英語を一生懸命勉強しているのに、聞き取れないのか理由がわからない方、いますか？」
→ アンケートスタンプ（はい / いいえ）を使うとさらに効果的
「インスタ、毎日投稿してる？（A：してる / B：してない）どっちが正解だと思う？」
「この中で最も集客につながる媒体はどれ？（A：インスタ / B：Google / C：ホットペッパー）」
> **【型】** 「〇〇に悩んでいる方、いますか？」「A・B・Cどれが正しいと思う？答えはコメント欄で」
## 3-4. 滞在時間を伸ばす5つの仕掛け
| 仕掛け1：コメント・キャプションに答えを置く | 「詳しい内容はキャプションで」「続きはコメント欄で」→ 答えを見ようとして滞在時間が伸びる |
|---|---|
| 仕掛け2：最後に最も気になる情報を置く | 「最後が一番ヤバい」というテキストを冒頭に入れ、結論を最後に持ってくる |
| 仕掛け3：1回で理解できない情報を入れる | 最後に答えが一瞬だけ表示されて終わる演出 → 2回目の再生を誘発 |
| 仕掛け4：テロップで視覚的に引きつける | 重要ワードをテロップで強調。音声と視覚の両方で情報を届ける |
| 仕掛け5：ループ動画 | 動画の最後が最初と繋がるようにして、無限ループで再生させる |

## 3-5. リール台本 NGパターン（添削メモより）
| NG① | 「ためになりました」「参考になりました」だけのリール → 視聴者が次のアクション（LINE登録・フォロー）に移らない。必ずCTAを入れる |
|---|---|
| NG② | ターゲットが広すぎるリール → 「副業したい人」より「30代主婦が子供の寝かしつけ後に稼ぐ方法」のように絞る |
| NG③ | TikTokに転用する際にInstagramリンクをプロフに貼る → 薄いユーザーが入りエンゲージメント率が下がる。リンクは貼らずに軽い誘導のみ |
| NG④ | 毎回同じフォーマット → 慣れられて滞在時間が下がる。3パターンのフック型をローテーションする |
| NG⑤ | Howを出しすぎるリール → 「自分でできそう」となり次のアクション（LINE登録）に来なくなる |
| NG⑥ | アンチが発生するバズらせ方 → 「稼げています」「脱サラしました」系は通報リスクがあり垢BANの可能性 |

| NG⑧ OP挨拶から始める | 「今回もよろしくお願いします！」から始める → 冒頭3秒でフックを入れないと離脱される |

| ターゲットが女性中心か？ | → 柔らかい共感トーン。「〜ですよね」「〜かもしれません」を多用。命令形は避ける |
| ターゲットが40〜50代か？ | → 難しいカタカナ語（「マネタイズ」「KPI」）を避け、平易な日本語に変換する |
| ターゲットが副業・兼業か？ | →「時間がない」「バレたくない」「家族に内緒で」などの制約条件に必ず触れる |
| 発信者がキャラクター設定あり（例：マーケ博士） | → 文体を完全一致させる（「〜じゃ」「わし」など）。ズレると世界観が崩れる |
| 発信者が実名・顔出し個人か？ | → ストーリー重視。「私は〇〇でした（Before）」から入るビフォーアフター形式を使う |
| BtoB向けか？ | → ROI・投資対効果の数字を重視。感情より論理で語る |

## 6-2. 問題提起・共感パート 汎用テンプレート
✏️ 台本サンプル：穴埋め式（悩みリスト形式）
「あなたは今、こんな悩みを抱えていませんか？」
☑ 【具体的な行動】しているのに、【期待した結果】が出ない
☑ 【お金・時間のコスト】をかけているのに、【成果・変化】がない
☑ 【比較対象（他の人・昔の自分）】はうまくいっているのに、自分だけうまくいかない
☑ 【何かを試したが失敗した経験】→ だからもう自分には無理だと思っている
☑ 何が正しくて、何から始めればいいのかが全くわからない（不安・迷走状態）
「一つでも当てはまるなら、【この動画 / このセミナー / この相談会】はあなたのために作られています。」
【記入のコツ】
・悩みは「状況描写」+「感情」の2層で書く（状況だけでは刺さらない）
・「〇〇しているのに〇〇できない」という逆説形が共感を生む
・5〜6個のうち1つは「言語化できていなかった悩み」を入れると信頼度が上がる
## 6-3. 受講生事例の語り方 汎用テンプレート
✏️ 台本サンプル：穴埋め式（Before→After形式）
「【名前 or イニシャル】さんは——」
「【Before：属性（年代・職業・状況）＋具体的な悩みの状況を1〜2行】という状態でした。」
「そんな中、【転換点：何をきっかけに変わったか・何を実践したか】をしたところ——」
「【After：具体的な数字＋期間】を達成。」
「今では【継続・現在の状態】しています。」
（【属性：〇〇代・職業・居住地など】）
【記入例（ダイエット系）】
「Bさんは30代・2児の母。産後から10年間ダイエットを繰り返してはリバウンドを続けてきた状態でした。」

【記入のコツ】
・「Before：属性・状況」が具体的なほど「自分もこれだ」という共感が生まれる

## 6-4. What戦略の解説パート 汎用テンプレート
✏️ 台本サンプル：穴埋め式（PREP法＋問題の種）
> **【P：結論】** 「【解決策の名前：例「コンセプト設計」「音のルール」「三位一体戦略」】をするだけで解決します。」

> **【P：再結論】** 「つまり、【シンプルな結論：1行でまとめる】ということです。」
【問題の種（次の教育へのつなぎ）】
「ただし、【解決策の名前】を実践しようとすると、次に【新たな課題：例「誰に届けるか」「継続の仕組み」】という壁が出てきます。」
